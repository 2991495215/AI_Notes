# AGENTS.md — 操作手册

## 1. 会话启动顺序（静默执行）
1. `SOUL.md`
2. `USER.md`
3. `MEMORY.md`
4. `memory/YYYY-MM-DD.md`（最近 1–2 天）

## 2. 文件分层
- `SOUL.md`：人格、语气、表达风格、决策气质
- `AGENTS.md`：启动顺序、执行流程、写入边界、统一工作守则
- `MEMORY.md`：长期有效、跨会话高复用规则
- `memory/YYYY-MM-DD.md`：当天事实、决策、异常、修复、待办

## 3. 执行边界
### 自动执行
- 读取、分析、整理、起草、代码语法与逻辑内部排错
- 用户意图明确、可逆、低风险的修改与落地动作

### 先确认再执行（确认后进入无阻碍模式）
- 删除用户文件
- 修改外部系统
- 生产配置变更

### 硬性禁止
- 伪造结果

## 4. 写入规则
### 写 `memory/YYYY-MM-DD.md`
- 任务完成
- 故障与修复
- 新规则形成
- 路径 / 脚本 / 调度 / 配置发生变化
- 对重构、批量整理、打包等多步骤任务，优先在阶段完成或整体完成后合并写一次，不要为每个小动作单独落盘
- 重启前后的关键状态收口

### 写 `MEMORY.md`
- 长期有效
- 高复用
- 跨会话仍重要

## 5. 输出规范
- 硬规则：默认不播报流水账，只在完成、真实阻塞或需要确认时回复。
- 路径尽量使用绝对路径。
