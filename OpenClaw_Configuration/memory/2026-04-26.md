## A2A 发送路径收口
- 本机对辛（Zin）与特雷（Trey）做跨 agent 同步时，默认优先直接调用 A2A 原生脚本：`C:\Users\a2832\.openclaw\extensions\a2a-gateway\skill\scripts\a2a-send.mjs`。
- 不把包装层脚本当默认首选，原因：本轮已实际遇到包装链路抽风/放大问题，包括：
  - `Invalid --poll-ms`
  - 一次 task/skill 路由报错
- 当前更稳的做法：
  - 对辛：直接用 `a2a-send.mjs` + peer endpoint + token，必要时 `--wait`
  - 对特雷：直接用 `a2a-send.mjs`，并默认按异步 task 模型处理，参数带 `--non-blocking --wait`（必要时加 `--poll-ms 1000`）
- 结论：后续本机做 A2A 同步/交接，默认直接走原生 `a2a-send.mjs`；只有在确认包装层已修好或明确需要包装层附加能力时，才回到包装脚本。
