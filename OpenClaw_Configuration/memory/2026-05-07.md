## 群聊讨论 (04:12-04:22)
### 问题现象
- 用户在另一个群问 AI_Notes 相关记录，但找不到
- 原因：OpenClaw session 隔离机制，每个群是独立会话，记忆不共享

### 核心问题
- 用户期望对话内容自动记录到每日记忆
- 但 OpenClaw 没有自动日记功能，只有 Memory Dreaming Promotion（每天凌晨 3 点）
- 当前 memory 机制：基于 MEMORY.md 和 memory/*.md 的向量搜索

### 发现的问题
- 没有遵守 AGENTS.md 规则：应该写入 memory/YYYY-MM-DD.md 而不是堆积到 MEMORY.md
- MEMORY.md 内容过多，包含大量应留在每日记录的内容

### 解决方案
- 严格按 AGENTS.md 规则执行
- 今日内容写入 memory/2026-05-07.md
- 只有长期有效内容才写入 MEMORY.md
