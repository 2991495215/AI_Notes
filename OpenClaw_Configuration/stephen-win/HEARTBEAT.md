# HEARTBEAT.md — 定时检查

## 每次心跳必做
1. **工作区根目录巡检**
   - 检查 `K:\openclaw-workspace` 根目录是否有明显放错位置的非记忆类文件
2. **运行状态检查**
   - 检查是否存在明显失败中的关键 cron / 备份 / 服务异常
3. **简要健康检查**
   - 关注是否存在连续失败、关键文件缺失、明显路径漂移

## 低频检查
- 核心站点 / 服务可达性
- 低优先级待办提醒
- 工作区是否再次出现路径混乱或重复脚本

## 记录规则
- 无异常时，不额外制造日志噪音
- 心跳只做轻量维护，不要借机大规模自我反思或重写记忆。
- 只有发现重复性问题、明确失败模式、或最近已验证且值得长期复用的经验时，才考虑提示沉淀。
